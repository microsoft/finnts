# Starter prompts

Offer these after setup or the tutorial, and whenever a user asks "what can I ask?".
Show only the few that fit where they are; replace the angle-bracket parts with their
real names. Users can phrase things any way they like.

## Getting started

- "Use the Finn skill to give me the Finn tutorial."
- "What does my data need to look like for Finn?"
- "Give me a data template I can fill in."
- "Use the Finn skill to forecast `<file>` 12 months ahead."
- "I have about 5,000 series. What settings do you suggest?"
- "Test Finn on a sample of 50 series from `<file>` first."

## Running forecasts

- "Run a standard forecast for `<project>`."
- "Run the Finn Agent on `<project>` to find the most accurate models."
- "How is my forecast going?" / "Show all my running forecasts."
- "Stop the run for `<project>`."
- "I have new actuals in `<file>`. Update the `<project>` forecast."

## Understanding results

- "Summarize the forecast for `<project>`."
- "Which series are least accurate, and why?"
- "What does WMAPE mean?" / "Explain back testing."
- "Why did the Agent pick these models for `<series>`?"
- "Compare this run with the last one."
- "Show the forecast and history for `<series>` in a chart."
- "Export the forecast to Excel."

## Housekeeping

- "List my Finn projects." / "How much disk space is Finn using?"
- "Is there a newer version of the Finn skill?" / "Undo the last update."
- "My run failed. What went wrong?"
- "Create a support report so I can report a problem."
- "What data leaves my computer when I use Finn?"
